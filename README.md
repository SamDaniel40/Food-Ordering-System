🍽️ Food Ordering System

A web-based application built with ASP.NET and SQL Server to streamline and modernize the process of ordering food online. This system allows users to browse menus, place and track orders, and manage their accounts with ease—while offering restaurants powerful tools for order and customer management.


---

🚀 Features

✅ User Registration & Authentication

📜 Dynamic Menu Management – Add, update, delete items

🛒 Cart & Order Management – Create, update, and view orders

💳 Secure Payment Processing – View transaction history

📊 Reporting System – Order, payment & sales reports

🔔 Real-Time Notifications – Order status updates (email-based)

🛠️ Admin Dashboard – Manage menu, orders & users

🔐 Data Security & Backups


---

💻 Tech Stack

Component	Technology

Frontend 	ASP.NET Web Forms
Backend 	C# (Visual Studio 2022)
Database	 SQL Server Management Studio 20.2
Web Server	IIS 7.5+
Framework	.NET Framework 4.0+

---

🧩 System Modules / Panels

🔐 1. Authentication Panel

> User Registration

> Login with Validation

> Admin Login

> Forgot Password (optional)


🍔 2. Menu Management Panel (Admin)

> Add Menu Items (name, category, description, price)

> Edit Menu Items

> Delete Menu Items

> Search Menu Items

> Update Item Availability Status


👥 3. Customer Panel

> View Profile / Edit Details

> Browse Menu

> Add Items to Cart

> Place Orders

> Track Order Status

> View Order History

> Manage Delivery Address & Payment Info


🛒 4. Order Management Panel (Admin)

> View New Orders

> Update Order Status (Pending → Confirmed → Out for   Delivery → Delivered)

> Order Search by Customer, Date, or Status

> Cancel or Modify Orders


💳 5. Payment Panel

> Choose Payment Method (Online/Cash)

> Process Payment

> View Payment History

> Filter Payments by Date/Customer


📊 6. Reports Panel (Admin)

> Order History Report

> Payment Report

> Sales Analytics

> Customer-wise Order Summary


📧 7. Email Notification Panel

Send Email on:

> User Registration

> Order Confirmation

> Order Delay

> Out for Delivery

> Order Delivered
